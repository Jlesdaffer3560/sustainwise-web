# Play Store listing assets

- `short_description.txt` — 77/80 chars, for the "Short description" field.
- `full_description.txt` — 1,914/4,000 chars, for the "Full description" field.
- `privacy_policy.md` — accurate as of today: the app collects no personal data and stores everything locally. **This must be hosted at a public URL before Play Console will accept it** — Play Console only accepts a link, not pasted text. Easiest free options: a GitHub Pages page, a Gist rendered via a service like htmlpreview, or a simple page on any site you already control. If you add real functionality later (e.g. wiring "Request free scan" to actually collect an email), update this file *and* the hosted copy first.

- `feature_graphic_1024x500.png` — the store listing's banner image.

## Still needed before submission (not covered here)

- Screenshots (needs the phone) — Play Store requires at least 2 phone screenshots, ideally 4-8.
- App category (Education fits) and content rating questionnaire — filled in directly in Play Console, nothing to draft.
- Play Console developer account ($25 one-time fee, per the original budget) if not already set up.
